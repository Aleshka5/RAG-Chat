# Спецификация RAG-чата по документам

**Версия:** 1.0
**Дата:** 2026-10-18
**Статус:** нормативная спецификация

Документы в этом каталоге заменяют исходный черновик. Решения, которые черновик содержал с ошибками, перечислены в [review.md](review.md). Остальные файлы самодостаточны: по ним можно реализовывать систему, не читая черновик.

Код системы — один репозиторий. Чем его писать и собирать, записано в [../AGENTS.md](../AGENTS.md).

## Что строим

Пользователь загружает PDF. Фоновый конвейер извлекает текст (для сканов — OCR), режет его на чанки, считает эмбеддинги и кладёт векторы в Qdrant. В чате вопрос ищется по всем готовым файлам этого пользователя, ответ даёт внешняя LLM с OpenAI-совместимым API, а в ответе есть ссылки на файл и страницу. Предпросмотр PDF открывается на этой странице. US-10 регистрирует изображения в отдельную коллекцию: одно изображение — один вектор, без OCR; текстовый запрос ищет эти векторы напрямую.

## Что не строим

| Компонент | Почему вне репозитория |
|-----------|------------------------|
| Auth Gateway | Уже существует. Проверяет access JWT и передаёт `X-Auth-User-Id`. Свой auth gateway не разрабатывается. Контракт — [gateway.md](gateway.md). |
| LLM | Внешний OpenAI-совместимый endpoint (`LLM_BASE_URL`). |
| MinIO, MongoDB, Qdrant, RabbitMQ | Инфраструктура. Сервисы её инициализируют при старте, но не реализуют. |

## Приоритет при расхождении

1. Для формы HTTP-запросов и ответов приоритет у `openapi.yaml` и `openapi-internal.yaml`.
2. Для побочных эффектов, статусов и алгоритмов приоритет у профильного документа (`api.md`, `processing.md`, `messaging.md`, `data-models.md`).
3. `review.md` ничего не предписывает.

Имена полей в JSON — `snake_case`. Время в API — UTC, ISO-8601 с суффиксом `Z`. Идентификаторы ресурсов — UUID.
